One line of software error copy that tells the brutal truth about what broke — and makes you laugh. Entry for the [Say What Actually Broke](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5) competition on make.fun.

## The line

> Save failed: the disk is full, and your 47 unsaved tabs of 'research' finally won. Free up some space, then save again before the browser eats the rest.

152 characters. One specific, instantly recognisable failure (a full disk), a concrete next step (free up space, then save again), and a twist born from the failure itself — the tabs won.

## How to run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`. Python standard library only, no network, deterministic — every run produces byte-identical output.
